Docker build/run notes:

    sudo docker build -f src/main/docker/compiler/Dockerfile -t mipasm-compiler .

    sudo docker run --rm -it -v "$PWD:/home/ubuntu/Flex-Bison-Compiler" -w /home/ubuntu/Flex-Bison-Compiler mipasm-compiler bash

  Once inside the container:

    chmod +x src/main/bash/*.sh
    bash src/main/bash/build.sh
    bash src/main/bash/test.sh

  Run one program manually:

    printf 'void main() { 1 + 2 }' | .build/Flex-Bison-Compiler

  Expected quick checks:

    printf 'void main() { 1 + 2 }' | .build/Flex-Bison-Compiler
    echo $?
    # should be 0

    printf '1 + 2' | .build/Flex-Bison-Compiler
